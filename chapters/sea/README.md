# 一江通海｜第二版完整网页

本文件夹是一套可独立发布到 GitHub Pages 的完整静态网站，包含网页源码、五幕底图、动效图层、水域遮罩和音效。它不会改动第一版目录。

## 本地预览

由于网页采用 ES 模块和 Three.js，建议启动本地静态服务器后预览：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000`。初次加载水面效果需要访问 jsDelivr 获取固定版本 Three.js；其余图片、音效和页面文件都在本目录中。浏览器不支持 WebGL 或 CDN 无法访问时，底图、船、人和知识卡仍会显示，只有 Three.js 水面波动不可用。

## 发布到 GitHub Pages

将本文件夹**全部内容**上传到目标 GitHub 仓库的 Pages 发布目录，保持 `index.html` 与 `assets/`、`js/` 同级，然后在仓库 Pages 设置中启用该目录。若放入仓库子目录，子目录路径仍使用相对地址，可正常部署在 `username.github.io/repository/`。

## 互动

- 五幕导航、前进/返回、重看、跳过当前动作和键盘左右方向键。
- 点击“开始行舟”后显示第一幕；声音按钮控制水声、风声、港口叫卖和迎亲吹奏。
- 第一幕船头朝右驶行；第二幕船从画面右侧靠岸，人物轻微行走、推车和搬货；第三幕人物执行提、搬、放动作；第四幕船在双塔前行；第五幕船缩小淡出后显示第一版结尾文案。
- 每幕含知识卡和两个热点卡。知识卡延续第一版视觉交互，并加入沉积港城关系、二号沉船船形与分舱、瓯窑和龙泉窑等内容。画面中的茶棚、人物和搬运情节未被写成知识点。
- Three.js 水面根据五张 PNG 黑白遮罩产生轻微画面折射，只作用于遮罩的白色水域。调整幅度时请复核岸线和船只位置。

## 目录

```text
index.html         页面结构与 GitHub Pages 元信息
style.css          响应式布局、卡片、导航和结尾样式
js/app.js          五幕文案、热点、音效、船与人物动作
js/water-scene.js  Three.js 水面着色器
assets/backgrounds 五张净底图
assets/masks       五张水域遮罩
assets/ships       船只透明层
assets/sprites     人物图集、道具、水纹
assets/audio       环境声、叫卖和迎亲吹奏 WAV
```

图片是生成式补绘与分层素材；船形插图用于场景动效，不代表沉船精确复原。知识卡里的实测尺寸和复原估计分别说明。叫卖为语音合成，迎亲吹奏为合成音色，不是真人录音。
